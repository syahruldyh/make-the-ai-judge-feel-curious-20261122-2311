# make-the-ai-judge-feel-curious-20261122-2311

Entry for the make.fun bounty
https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311

`main.py` writes one short text to `/output/entry.txt` — a small family
story about a grandmother, a locked drawer, and a key taped under the
kitchen table with the note 'not yet.' The drawer is still locked. The key
is in the narrator's pocket. Nothing in it tells the reader to wonder; the
unanswered question does the work.
